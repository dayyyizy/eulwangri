# 을왕리 원정대 🌊

SAP VA·DVA 1박 2일 워크숍(11.17–18) 안내 페이지예요. 링크만 열면 로그인 없이 참여할 수 있어요.

- `index.html` 페이지 본체
- `firebase-config.js` Firebase 웹 앱 설정값 (공개돼도 되는 식별용 값)
- `shim.js` 페이지와 Firebase(실시간 저장소 · 익명 로그인)를 잇는 연결부
- `img/` 장소 사진 · `vendor/` Firebase SDK 10.12.2

관리실은 페이지 맨 아래 ‘관리자 로그인’에서 총괄의 구글 계정으로만 열려요. 어릴 적 사진과 식사 체크 내용은 Firestore 보안 규칙으로 총괄만 읽을 수 있어요.
